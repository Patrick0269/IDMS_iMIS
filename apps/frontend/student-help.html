Help and Support

Read student panel instructions and common answers, or send a helpdesk ticket to IDMC.

Student Panel Instructions

  1. Use the sidebar to open registration, profile, documents, timetables and academic records.
  2. Use Academic Results and Coursework Scores to view marks that have been released by IDMC.
  3. Use Financial to review invoices, payment requests, receipts and account balance.
  4. Submit official student requests through Requests and follow their status in Request History.
  5. Use Notifications for IDMC notices. Contact Helpdesk if a page or record is unavailable.

Frequently Asked Questions

How do I register courses?

Open Student Info → Registered Modules, review courses available for your current semester, then follow the registration actions shown there.

Where can I see examination results?

Open Academic → Results. Only results released by IDMC are shown.

How can I request a transcript or student ID card?

Open Requests, select the request type, enter the reason and submit. Track updates in Request History.

How can I review fees and payments?

Open Financial to review your fee statement, payments, receipts and outstanding balance.

How do I change my password?

Open Security → Password and security and submit a new password that meets the displayed security rules.
