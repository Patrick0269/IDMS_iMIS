# IDMC CURRICULUM STRUCTURE

Each programme can have multiple curriculum versions.

Example:

Programme:
Diploma in Clinical Medicine

Curriculum:
2026 Version

Academic Year:
2026/2027

NTA Level:
Configured by institution

Semester:
Semester I / Semester II

Each curriculum contains:

Course Code
Course Name
Course Type
Credits
Hours
Semester
Year of Study
Prerequisites
Status

Curriculum statuses:

Draft
Under Review
Approved
Active
Retired
Archived

Important Rule:

An approved/active curriculum must not be edited destructively.

If major changes are required:
Create a new curriculum version.
