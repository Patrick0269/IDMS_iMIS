# IDMC USER LIFECYCLE

Applicant:

Register Account
↓
Verify Email/Phone
↓
Submit Application
↓
Admission
↓
Student Account

Student:

Applicant
↓
Admitted
↓
Registered
↓
Active Student
↓
Graduated / Withdrawn / Suspended
↓
Alumni where applicable

Staff:

User Created
↓
Employee Record
↓
Role Assigned
↓
Department/Campus Assigned
↓
Active
↓
Leave / Suspended where applicable
↓
Employment Ended
↓
Account Disabled

## IMPORTANT

Disabling a user must not delete historical records.

Historical academic, financial, HR and audit records must remain intact.
